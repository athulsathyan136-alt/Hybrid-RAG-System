# 🤖 Day 6 — RAG Pipeline

A Retrieval-Augmented Generation (RAG) pipeline built using Python, Sentence Transformers, FAISS, and Hugging Face Transformers.

## Architecture

User Question
↓
Query Embedding
↓
FAISS Vector Search
↓
Relevant Context
↓
Language Model
↓
AI Answer

## Technologies

- Python
- Sentence Transformers
- FAISS
- NumPy
- Hugging Face Transformers
- FLAN-T5

## Features

- Semantic document retrieval
- Vector similarity search
- Context retrieval
- AI answer generation
- Interactive question answering
